Automatic updates

AdoptIQ checks the synced OneDrive AI Projects/OUTBOX Releases folder for a newer build. Choose how updates are applied on this machine:

  • Automatic — download, verify (SHA-256 + code signature), and silently replace the app when no analysis is running, then relaunch.
  • Notify only — show a banner when a new build is available; you click to install.
  • Off — never check for updates.
