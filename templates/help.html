Help & Documentation

Everything you need to know about using AdoptIQ effectively.

Getting Started
1. Install Dependencies

Make sure you have all required packages installed:

pip install -r requirements.txt
2. Configure Credentials

Create a .env file with your Cisco credentials:

KEEPER_ROLE_ID=your_role_id
KEEPER_SECRET_ID=your_secret_id
CIRCUIT_CLIENT_ID=your_client_id
CIRCUIT_CLIENT_SECRET=your_client_secret
3. Start the Application

Run the web application:

python app_simple.py
4. Open Your Browser

Navigate to http://localhost:5001

Running Analysis
Step-by-Step Process
1
Select Manager Team: Choose the manager whose portfolio you want to analyze
2
Choose Technology: Focus on specific areas or analyze all technologies
3
Set Time Range: Specify how many days back to analyze (1-365)
4
CSOne Data: Access latest AdoptIQ Export from CSOne via link, or run your own report and browse to select
5
Run Analysis: Click the button and wait for completion
Recommended Settings
Quick Review: 30-60 days
Standard Analysis: 90 days
Deep Dive: 180 days
Trend Analysis: Start with "All Technologies"
Understanding Outputs
Word Document (.docx)

The Word report contains:

  • Portfolio Health Score: Overall grade (A-F) with justification
  • Executive Summary: High-level insights and strategic implications
  • Top Customers: Most engaged customers by activity volume
  • Cross-Cutting Themes: Issues affecting multiple customers
  • Customer Deep Dives: Individual customer analysis with recommendations
Excel Spreadsheet (.xlsx)

The Excel file contains multiple sheets:

  • AB_Detail_All: All adoption barriers with categorization
  • CSOne_Detail_All: TAC case details and references
  • External_Bugs: Public bug references from help.webex.com
  • External_Incidents: Service status and maintenance information
Troubleshooting
Common Issues & Solutions
Import Errors

Symptom: "ModuleNotFoundError" or similar

Solution: Run pip install -r requirements.txt

Database Connection Issues

Symptom: "Connection failed", "Keeper Connection Error", or timeout errors

Solution: Verify Keeper credentials and network connectivity

File Upload Problems

Symptom: Upload fails or file not recognized

Solution: Ensure file is .xlsx/.xls format and under 50MB

Analysis Failures

Symptom: Analysis stops or produces errors

Solution: Check error logs in outputs/ directory

Best Practices
For Optimal Results
Always use the latest CSOne export for most accurate case data
Start with broader analysis (All Technologies) then drill down
Use 90+ days for meaningful trend identification
Review external intelligence to correlate with internal data
Save reports for historical comparison and tracking
Data Quality Tips
Ensure CSOne files have proper column headers
Verify customer names match between systems
Check that technology classifications are accurate
Review adoption barrier categories for consistency
